# Topdeck 验收清单

每项三选一：通过、失败、跳过。失败时记下现象，不用写原因。

## 开始之前

1. 从菜单栏的 Topdeck 图标打开 Settings。
2. 这些功能默认关闭，要先在 Settings › Shortcuts & Windows 或各空间页里打开：Windows、Window Switcher、Command Bar、Input Sources、Storage、System Admin。
3. 系统弹权限时按需允许：辅助功能、屏幕录制、日历、定位（天气）。

## 优先验收

### Now

- [ ] 第一次打开 Now 时系统询问位置权限，允许后天气出现；拒绝后只显示 Weather unavailable 和 Open Settings
- [ ] 右栏底部的 Apple Weather 标志能打开 Apple 的法律页面；标志没加载出来时显示文字 Weather，同样是链接
- [ ] 用带 WeatherKit 描述文件签名的构建（`make install`）天气能出来；没有描述文件的构建显示 Weather unavailable，不崩溃
- [ ] 正在播放（含浏览器里的音频）时右栏出现播放器；拖动进度条时时间和歌词跟着变，松手才跳转
- [ ] 加号能打开输入框；Return 保存，Tab 切换 Event / Note，Esc 只关输入框（丢弃文字，面板不关），点别处也会关闭
- [ ] 选 Note 时输入框出现五个颜色点和 Desktop、On Top 两个开关，两者互斥、默认都关；按 Return 保存后便签带着所选颜色和位置
- [ ] 点月历里的日期出现圆环并列出当天事件，再点一次回到未来 7 天；右键自己的事件能编辑、删除，编辑弹出框能输入
- [ ] 点左栏便签在浮动窗口里打开，可读可改，关掉窗口便签还在；已钉住的便签窗口被带到前面
- [ ] 右键便签：各个颜色、Pin to Desktop、Keep on Top、Unpin、在 Finder 中显示、删除（有确认）
- [ ] 左栏便签前的小方块颜色与便签一致；Control-Option-N 打开 Now 并进入 Note 输入
- [ ] 最小尺寸 620×340 下各状态没有被截断

### 便签

- [ ] 便签的右键菜单和窗口上的按钮能切到桌面、置顶、收回刘海
- [ ] 桌面便签在普通窗口之下，置顶便签在普通窗口之上
- [ ] 置顶便签能盖在全屏 App 上
- [ ] 切换桌面空间后，两种便签都还在
- [ ] 台前调度和“显示桌面”下表现正常
- [ ] 中文输入：候选框位置对，回车确认后文字进便签
- [ ] ⌘C、⌘V、⌘A、⌘Z 都可用
- [ ] 拖动和改变大小后，重启 Topdeck 位置不变
- [ ] 拔掉外屏后便签回到主屏，接回后回到原位
- [ ] 文件被其他设备或编辑器改写后，便签内容跟着更新

### 刘海审批

连接 Claude Code：Settings > Agents。这一步会写入 `~/.claude/settings.json`。请求和等待中的会话显示在 Agents 页左栏。

- [ ] 请求出现时，刘海有举手提示，终端也同时显示提示
- [ ] Allow、Deny 都能把结果传回 Claude Code
- [ ] Always Allow 按钮上写着具体规则
- [ ] 两个请求排队时双击 Allow，第二个不会被连带批准
- [ ] 在终端里回答后，刘海的卡片消失
- [ ] 提问能在刘海里回答
- [ ] 退出 Topdeck 后，权限提示回到终端，没有自动批准

### 窗口切换

- [ ] Option-Tab 在各种 App 前台都能呼出
- [ ] 按住 Option 时 Tab 能移动，松开后切到选中窗口
- [ ] 快速轻点一下切到上一个窗口
- [ ] 输入文字能过滤，Escape 取消
- [ ] 最小化窗口能恢复，全屏 App 上方也能显示

### 命令栏

- [ ] Option-Space 呼出，失去焦点后关闭，焦点回到原 App
- [ ] 能搜到 App 和 Topdeck 动作，也能按标题和开头的文字搜到便签，回车在浮动窗口里打开
- [ ] 中文组字时按回车只确认文字，不执行结果
- [ ] 窗口动作作用在原来的前台窗口

### 菜单栏

- [ ] 更新后菜单栏里只剩 Topdeck 自己的一个图标，旧版菜单栏隐藏留下的两个图标没有了，被隐藏过的图标都在
- [ ] 图标是新的刘海形状，亮色和暗色菜单栏下都看得清

### 颜色与图标

- [ ] 面板顶部纯黑与刘海相接，往下 55 点渐变到深蓝灰；六个空间的强调色各不相同
- [ ] 打开哪个空间，它的标签就是那个颜色的胶囊
- [ ] Dock、Finder、关于页里的新图标在 16、32 点处还认得出刘海
- [ ] 刘海收起、正在播放时，摄像头旁是四根细条，颜色跟着封面，随节奏式的图案起伏；暂停后变矮不动；系统开启“减弱动态效果”后不动

### Settings

- [ ] 侧栏里空间页面按 Now、Shelf、Clipboard、Tools、Agents、Mac 排列，其后是 Shortcuts & Windows
- [ ] Shortcuts & Windows 的每一节（Windows、Window Switcher、Command Bar、Input Sources）都以开关和触发方式开头

### Shelf 与 Clipboard

- [ ] Shelf：文件显示为 3 列大缩略图（图片、PDF 有真实预览，其余是类型色加扩展名），名称下是“类型, 大小”
- [ ] Shelf：单击选中，Command 单击多选，双击打开，空格预览；整块拖出去是文件；右键菜单仍有显示、AirDrop、上传
- [ ] Shelf：把图块或 Finder 里的文件拖到 AirDrop、Upload to R2、Add to Note、Open With 上都能执行；未配置 R2 时上传项是灰的
- [ ] Shelf：Add to Note 新建一条笔记（文本文件放内容，其他放路径）；Open With 弹出可用 App 列表
- [ ] Shelf：空货架只有一行字，拖文件靠近时有投放高亮；700×430 与 620×340 都不挤
- [ ] Clipboard：筛选 All、Text、Images、Links、Files 正确；图片行是真缩略图，右侧大图按比例显示
- [ ] Clipboard：上下键换选中项，回车粘贴，直接打字进入搜索；右上菜单里有选择、清空、纯文本粘贴、去跟踪、关闭历史
- [ ] Clipboard：从 Finder、浏览器、预览、截图复制图片都进历史并有缩略图（含整屏 Retina 大图）
- [ ] 每次截图都自动进 Clipboard 历史，来源是 Topdeck，系统剪贴板不被改；截图又被复制时不出现两条；历史关闭时不记；录屏不记

### Tools、Agents 与 Mac（第三轮第三批）

- [ ] Tools：第一行 Area、Window、Screen、Scrolling、Text 都能截图；Window 能高亮并点选窗口，Screen 截整块屏幕且不含刘海
- [ ] Tools：Record Window、Record Screen、Edit Video 可点，没有 Record Area
- [ ] Tools：最近截图是真实缩略图，带 PNG 角标和时间；点击在编辑器里打开，拖出去是文件，右键有 Copy、Reveal、Delete（进废纸篓）
- [ ] Tools：Timer、Keep Awake、Pick Colour、Shortcuts 点开是弹出层，原有控件都在；最近颜色在 Pick Colour 的弹出层里；Sleep Screen 一点就熄屏
- [ ] Tools：700×430 与 620×340 都不挤，小尺寸下缩略图变矮
- [ ] Mac：六张卡片有数值、折线和一行说明；折线只在页面打开时积累，离开后清空；没有电池的 Mac 显示开机时长
- [ ] Mac：进程表点表头换排序，620×340 下先去掉进程行
- [ ] Mac：音量滑块和点图标静音可用；接外接显示器时有亮度滑块
- [ ] Mac：点 Sound、Displays、Network、Storage、System 时对应页面从右滑入盖住整个主体，返回按钮回到卡片；Storage 的清单和确认、每个 App 的音量、Homebrew、启动项都还在
- [ ] Agents：左栏先是等待批准的请求，再是运行中的会话；点会话回到它的终端；结束或空闲的不列出；都没有时左栏和竖线消失
- [ ] Agents：标题是 “N waiting”，没有等待时是 “Agents”；Today、7 Days、30 Days、All 切换后重启仍记得
- [ ] Agents：圆环中间是总费用，每个工具一行（颜色点、名称、tokens、费用）；All 包含日志里还留着的全部历史
- [ ] Agents：配额块里 5h、W、M 的条、剩余百分比、重置时间和“均匀用量”刻度；读不到的工具显示 Checking…、Sign in 或 Unavailable，不是 0
- [ ] Agents：Cline 有 tokens 和费用；Cline CLI 已登录时才有配额条
- [ ] 价格表最多一天取一次（只访问 PRIVACY.md 里列的地址）

### 录屏（第三轮第四批）

只用自己的屏幕和窗口试，不要对着含有隐私的内容。

- [ ] Record Window：高亮并点选窗口后，刘海里倒数 3、2、1，按 Esc 能取消，取消后什么也没录
- [ ] Record Screen：只有一块显示器时直接倒数；接多块显示器时在指针处弹出显示器菜单
- [ ] Record Tile 角上的小按钮打开弹出层：System audio、Microphone 默认关，Show clicks 默认开，重启后记得
- [ ] 第一次打开 Microphone 录制时系统询问麦克风权限；拒绝后照样录屏，刘海提示一次麦克风已关
- [ ] 录制中刘海（收起时）是红点加已录时长；指针放上去变成 Pause 和 Stop，悬停不会展开面板，点刘海才展开到 Tools
- [ ] 暂停后红点变空心、时长不走；继续后文件里没有暂停的那段
- [ ] 录制中，播放音乐时刘海显示的是录制而不是音乐条；系统开启“减弱动态效果”后不动
- [ ] 画面里没有 Topdeck 自己的任何窗口（刘海、面板、浮动便签）；打开 Show clicks 时点击处有橘色圆环（整屏录制）
- [ ] 开着 System audio 录一段有声音的视频，声音在文件里；开着 Microphone 说话，声音在另一条音轨里
- [ ] Stop 后文件保存在 Captures 里，名字是 “Screen Recording 日期 at 时间.mp4”（窗口是 “Window Recording …”），最近列表里有 MP4 角标和缩略图，视频编辑器自动打开
- [ ] 录制中 Tools 的两个 Record 磁贴都显示 Stop，点一下就结束
- [ ] 录制中系统不熄屏（`pmset -g assertions` 里有 Topdeck 的条目），结束后条目消失
- [ ] 录窗口时关掉那个窗口：录制干净地结束，已录的文件保留，刘海只提示一次，编辑器不自动打开
- [ ] 录制中到“隐私与安全性 › 屏幕录制”里关掉 Topdeck：录制结束并保留文件，只提示一次
- [ ] 磁盘剩余很少时（小于 200 MB）录制自动结束并保留文件
- [ ] 录制中退出 Topdeck：文件是完整的，能播放
- [ ] 删除一条录制：视频和旁边的 .json 一起进废纸篓

## 一般验收

### 窗口管理

- [ ] 半屏、三分、四分、接近最大化、下一屏的快捷键都正确
- [ ] 重复按同一快捷键时大小循环
- [ ] 拖到屏幕边缘能吸附，有预览
- [ ] 保存布局后能恢复

### 截图

- [ ] Control-Option-S 截图，标注后能复制、贴图、放进文件架
- [ ] 打码后的内容看不出原文
- [ ] 钉住的便签和贴图会出现在截图里
- [ ] OCR 能认中英文，二维码能识别，取色正确
- [ ] 滚动截图拼接无重复、无错位，Escape 能取消

### 剪贴板

- [ ] 纯文本粘贴、点选后直接粘贴可用（菜单里的开关，或行上右键）
- [ ] 链接的跟踪参数被去掉
- [ ] 忽略名单里的 App 和密码管理器不进历史

### 输入法

- [ ] 给 App 指定输入法后，切换到它时自动切换
- [ ] 未指定的 App 记住上次的输入法
- [ ] 中文输入法切换可靠

### 显示器

- [ ] 外屏亮度和音量可调，或显示为不可用
- [ ] 一键休眠让所有显示器熄屏

### 防休眠

- [ ] 定时、到指定时刻、一直开启都能按时结束
- [ ] “保持屏幕常亮”开关生效

### 存储

- [ ] 扫描只在点击后开始
- [ ] Xcode 运行时不能清理 Xcode 项目
- [ ] 删除前有清单，文件进废纸篓且能恢复
- [ ] `~/Library/Keychains`、`~/.ssh`、`~/.gnupg` 不能被选中

### 系统管理

- [ ] 启动项列表正确，系统项只读
- [ ] 停用、移除前会确认
- [ ] Homebrew 列表正确，升级、卸载、doctor 有输出且能取消

### R2

- [ ] 上传成功，公开链接已复制
- [ ] 同名文件不会被覆盖，“Replace in R2”能替换
- [ ] 密钥只在钥匙串里

### 性能

- [ ] 各项读数合理，温度和电池数据接近系统显示
- [ ] 打开标签页时动画不掉帧
- [ ] 离开标签页后 Topdeck 的 CPU 回落

## 收尾

- [ ] 用完后到 Settings > Agents 断开 Claude Code，或保留连接继续用
