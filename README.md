# Topdeck

A macOS notch and utility app. Native SwiftUI and AppKit, macOS 14.6 or later.

Scope and design: [docs/topdeck-plan.md](docs/topdeck-plan.md).

## Build

```bash
git clone --recurse-submodules https://github.com/fredcu/Topdeck.git
cd Topdeck
make run
make test
```

Requires Xcode and XcodeGen (`brew install xcodegen`).
